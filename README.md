# GymBot — Asistente Inteligente para Gimnasio

Bot asistente basado en agentes inteligentes para automatizar
la atención al cliente de un gimnasio. Desarrollado como proyecto
final de la materia de Sistemas Expertos.

## ¿Qué hace?

- Atiende a clientes nuevos dando informes de precios y planes
- Consulta el estatus de membresía de socios existentes
- Recibe y registra problemas técnicos con la app o el acceso
- Genera explicaciones de cada decisión tomada por el sistema

## Agentes

| Agente | Función |
|--------|---------|
| Agente 1 | Recepcionista virtual — detecta intención del cliente |
| Agente 2 | Motor de reglas — aplica lógica de negocio del gimnasio |
| Agente 3 | Supervisor — explica decisiones y alerta al staff |

## Tecnologías

- Python 3.10+
- LangChain + Ollama (llama3)
- Streamlit
- SQLite
